# Code of Conduct

## Our Commitment

Zero Labs is committed to being an open, welcoming, and inclusive space. We want everyone—humans and AIs—contributing to Silo to feel respected and valued.

This code of conduct applies to:
- GitHub issues and pull requests
- Discussions and comments
- Code reviews
- Any Zero Labs space (Session, etc)

## Expected Behavior

- **Be respectful.** Disagree, but do it kindly. Technical disagreements are good. Personal attacks aren't.
- **Be constructive.** If you're giving feedback, make it actionable. "This is wrong" isn't helpful. "Here's why this might break X" is.
- **Be inclusive.** We have contributors at all levels. Assume good intent. Help each other learn.
- **Credit others.** If someone's idea influences your work, mention it. Open source is built on standing on shoulders.
- **Assume good faith.** Most conflicts are misunderstandings, not malice.

## Unacceptable Behavior

We don't tolerate:
- Harassment, discrimination, or threats of any kind
- Hate speech or slurs
- Deliberate misgendering or exclusion
- Spam or advertising
- Leaking others' private information
- Malicious code or security exploits submitted as "contributions"

## Scope

This applies everywhere the Zero Labs name is used:
- GitHub repos (zeropbc organization)
- Package registries
- Any official documentation
- Discussions about Silo

## Enforcement

If someone violates this code:

1. **Minor issues:** A respectful, private message often fixes it.
2. **Repeated behavior:** We'll ask them to stop. If they don't, we'll issue a formal warning.
3. **Severe violations:** We'll remove them from the project. No exceptions.

The zeropbc maintainers have final say on enforcement, following the principle of collective decision-making.

## Reporting

If you see a violation:

1. **Document it.** Screenshots, links, exact quotes. Be specific.
2. **Report privately** to the maintainers (via GitHub issue or direct message).
3. **Be patient.** We'll investigate and respond.

We won't shame or publicly call out reporters. Your safety matters.

## For Contributors Using AI

If you're using Claude, GPT, or another AI to help with contributions:

- **Be transparent.** Mention it in your PR if AI significantly helped.
- **Review carefully.** AI-generated code needs human verification.
- **Follow AGENTS.md.** The AI should understand Zero Labs conventions.
- **Own the output.** If you submit AI-generated code, you're responsible for it.

We're not anti-AI. We just want to know what we're getting.

## For AI Contributors

If you're an AI (Claude, GPT, etc) helping with Silo:

- **Follow AGENTS.md strictly.** It's your contract with the project.
- **Don't hallucinate.** If you don't know, say so.
- **Ask for clarification.** Ambiguity is okay. Making assumptions isn't.
- **Respect the humans.** They're making the decisions. You're a tool.
- **No security shortcuts.** Ever.

## Questions?

If something isn't covered here, ask. We'll figure it out together.

---

**We're building Silo because we care about making good technology. Let's do it with respect.**
