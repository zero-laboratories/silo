# Roadmap for Silo
> Updated every major version, i.e. v1, v2

## V0.4: Polish + edge cases [Done]
- Handle errors gracefully (network timeouts, invalid keys, model limits)
- Streaming interrupts (Ctrl+C handling)
- Message formatting edge cases
- Config validation

## V0.5: UX refinement [Done]
- Keyboard shortcuts guide (? key shows help)
- Chat title auto-generation
- Better empty state messaging
- Smoother transitions between views

## V0.6: Advanced features [Done]
- Search within chat (Ctrl+F)
- Chat tagging/organizing
- Custom system prompts per chat
- Message editing/deletion

## V0.7: Pre-beta stability
- Full test coverage
- Performance optimization
- Documentation polish
- Release notes automation

## V0.8 - part of V1-beta
- Work mode UI
- Cowork context handling
- Mode switching (Chat ↔ Work)
- Beta testing framework

## V0.9 - finale for V1-beta
- MCP server integration
- Improve Work mode
- Filesystem access for Work
- SKILLS support via SKILL.md
- Web Search support
